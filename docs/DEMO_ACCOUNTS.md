## Import and persistence

With `SEED_COMPANY=true`, startup imports a changed `org-tree.json` and seeds the portfolio once. `./scripts/seed.ps1` runs the same workflow. Validation rejects duplicate emails or malformed children before changing the organization. A persisted checksum prevents an unchanged source file from overwriting in-app edits. Editing the source and importing again intentionally reapplies its reporting and department structure. Existing passwords and work updates are preserved. The packaged copy in `backend/app/seed/data/org-tree.json` is a fallback when the root file is absent.

The original seven fictional pilot logins are inactive, and the previous generic demo projects/commitments are archived from current dashboards, profiles, capacity, and workflow reminders. Their records remain in the database. Pre-import recovery copies are in `data/backups/`. SQLite records persist in `data/teampulse.db`; `./scripts/backup.ps1` creates a verified backup.

WhatsApp remains unconfigured and sends nothing. The in-app channel works end to end. Model credentials are optional; without them, chat clearly displays the structured offline helper.
